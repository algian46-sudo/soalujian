Integrasi Google Spreadsheet

Jika dikosongkan, tombol "Kirim ke Google Spreadsheet" tetap berfungsi dalam Mode Simulasi Kelas (menyimpan rekap & siap diunduh ke CSV/Excel).

Panduan Cepat Untuk Guru (Google Apps Script)
  1. Buka Google Sheets baru, buat header kolom: Waktu | Nama Anggota | Kelas | Kelompok | Jenis Podcast | Narasumber | Naskah.
  2. Klik menu Ekstensi (Extensions) > Apps Script, lalu tempel kode di bawah ini.
  3. Klik Terapkan (Deploy) > Deployment baru > Aplikasi Web (Akses: Siapa saja / Anyone), lalu salin URL-nya ke kolom di atas.
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  data.rows.forEach(function(row) {
    sheet.appendRow([
      new Date(),
      row.anggota,
      row.kelas,
      row.kelompok,
      row.jenis,
      row.narasumber,
      row.naskah
    ]);
  });
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
